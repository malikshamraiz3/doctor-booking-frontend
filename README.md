# 🏥 Doctor Booking Frontend

React + TypeScript frontend for Doctor Appointment Booking System.

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Axios
- React Router DOM
- Zustand (State Management)

## Features
- Patient registration & login
- Browse doctors with filters
- Book appointments with slot selection
- View & cancel appointments
- Admin dashboard with status management

## Backend Repo
https://github.com/malikshamraiz3/doctor-booking-api

## Setup
1. Clone repo
2. npm install
3. npm run dev
